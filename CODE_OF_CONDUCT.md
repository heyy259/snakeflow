# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Participants are expected to create an open, welcoming, inclusive, and healthy
community. Harassment, personal attacks, discrimination, and publishing another
person's private information are not acceptable.

## Reporting

Report conduct concerns privately through the contact channel listed on the
maintainer's [GitHub profile](https://github.com/heyy259). Do not include
sensitive personal details in a public issue.

Maintainers will review reports promptly, protect the reporter's privacy, and
take proportionate corrective action.

## Scope

This policy applies in repository discussions, pull requests, reviews, issues,
events, and other spaces where someone represents the project.
